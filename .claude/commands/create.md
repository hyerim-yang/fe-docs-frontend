새로운 문서 페이지를 생성합니다.

## 입력

사용자가 제공한 인자: $ARGUMENTS

인자 형식: `<폴더명> <문서제목> <작성자>`
예시: `/create git-guide Git 브랜치 전략 가이드 홍길동`

## 규칙

1. **반드시** `src/app/docs/_template/page.tsx` 템플릿을 기반으로 생성할 것
2. 템플릿의 레이아웃, 스타일, 구조를 절대 변경하지 말 것
3. 아래 절차를 순서대로 수행할 것

## 절차

### 1단계: 인자 파싱

- 첫 번째 단어 → 폴더명 (kebab-case, 영문)
- 마지막 단어 → 작성자
- 중간 단어들 → 문서 제목

인자가 부족하면 사용자에게 물어볼 것:

- 폴더명이 없으면: "폴더명을 입력해주세요 (영문 kebab-case, 예: git-guide)"
- 제목이 없으면: "문서 제목을 입력해주세요"
- 작성자가 없으면: "작성자 이름을 입력해주세요"

### 2단계: 템플릿 복사

1. `src/app/docs/_template/page.tsx` 파일을 읽는다
2. `src/app/docs/<폴더명>/page.tsx` 경로에 새 파일을 생성한다
3. `meta` 객체를 수정한다:
   - `title` → 사용자가 지정한 문서 제목
   - `author` → 사용자가 지정한 작성자
   - `createdAt` → 오늘 날짜 (YYYY-MM-DD)
   - `updatedAt` → 오늘 날짜 (YYYY-MM-DD)
4. 함수명을 `TemplatePage`에서 폴더명 기반 PascalCase로 변경한다 (예: `git-guide` → `GitGuidePage`)
5. 상단 주석 블록(사용법 안내)은 제거한다

### 3단계: 목록에 등록

`src/app/page.tsx`의 `docs` 배열에 새 항목을 추가한다:

```ts
{
  title: "<문서 제목>",
  meta: "작성자 : <작성자>",
  href: "/docs/<폴더명>",
}
```

### 4단계: 확인

- 생성된 파일 경로를 알려준다
- `npm run lint`로 린트 검사를 실행한다
- 에러가 있으면 수정한다

## 중요

- 본문 영역(`<div className="space-y-14 ...">` 내부)은 섹션 예시 하나만 남겨둘 것
- 템플릿에 없는 클래스나 구조를 임의로 추가하지 말 것
- 뒤로가기 링크, 제목/메타 헤더 영역의 마크업은 그대로 유지할 것
